# Batch 11 — Student Projects

Welcome to the official project repository for **Full Stack Web Development — Batch 11**.

This repository is created to collect, organize, and manage the projects and assignments completed by Batch 11 students throughout their learning journey.

### Roles

* **Students:** Develop and submit their projects and assignments through their assigned branches.
* **Mentor:** Guides students, reviews their work, and provides feedback and support.
* **Instructor / Viewer:** Has access to the repository for monitoring and reviewing progress. No regular project management or development tasks are assigned.

## 🌿 Branches

Each student has a dedicated branch for their projects.

```text
main
├── abdul-moez
├── shahid
└── ihtesham
```

The `main` branch is reserved for the primary repository content and overall repository management.

## 📁 Project Organization

Students should organize their projects by week:

```text
your-branch/
│
├── week-01/
├── week-02/
├── week-03/
└── ...
```

Example:

```text
abdul-moez/
│
├── week-01/
│   ├── index.html
│   └── style.css
│
├── week-02/
│   ├── index.html
│   └── style.css
│
└── week-03/
    ├── index.html
    ├── style.css
    └── script.js
```

## 📌 Student Guidelines

* Work only on your assigned branch.
* Do not directly modify the `main` branch.
* Do not modify another student's branch or projects.
* Organize projects according to their respective weeks.
* Use meaningful file and folder names.
* Write clean and readable code.
* Commit changes with clear commit messages.
* Push completed work regularly.

## 🔄 Submission Workflow

```text
Complete Project
       ↓
Add Project to Assigned Branch
       ↓
Commit Changes
       ↓
Push to GitHub
       ↓
Mentor / Instructor Review
```
